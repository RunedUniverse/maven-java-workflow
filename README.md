# Maven Java Workflow

[![Apache License, Version 2.0, January 2004](https://img.shields.io/github/license/apache/maven?label=License)](LICENSE)
[![MvnRepository](https://badges.mvnrepository.com/badge/net.runeduniverse.tools.maven.workflow/maven-java-workflow/badge.svg?label=MvnRepository)](https://mvnrepository.com/artifact/net.runeduniverse.tools.maven.workflow/maven-java-workflow)

The R4M Maven Java Workflow, provides:

- r4m-metadata (execution modes & configurations for Maven)
<br>designed for normal Java libraries and projects
- Project setup goals to simplify Pipeline configuration & maintenance (coming soon...)

```xml
<plugin>
  <groupId>net.runeduniverse.tools.maven.workflow</groupId>
  <artifactId>maven-java-workflow</artifactId>
  <version>0.1.0</version>
</plugin>
```
